# Drug Safety Analysis - Hypothesis Testing in Healthcare

## Project Overview: 
This project evaluates whether a hypothetical pharmaceutical drug causes statistically significant adverse reactions. The analysis is conducted using Python and supports independent drug safety reporting.

## Tools & Technologies
- Python
- pandas, scipy, statsmodels
- Jupyter Notebook

## Business / Research Questions
- Are adverse reactions significantly higher than expected?
- Does age influence adverse reactions?
- Can this drug be considered safe based on statistical evidence?

## Key Insights
- Certain adverse reactions were statistically significant
- Age groups showed meaningful differences in reaction rates
- Results demonstrate how statistics can inform drug safety decisions

## Skills Demonstrated
- Hypothesis testing
- Statistical reasoning
- Data cleaning & analysis
- Business interpretation of results
